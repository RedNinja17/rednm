Raspberry Pi 5 Server + Minecraft Server

Setting up a Raspberry Pi 5 as a headless server to host a lightweight Minecraft server instance. Goals include containerized deployment, automated backups to an external drive, remote monitoring, and optimizing performance for small groups.

Planning Stage

Select OS image, plan networking (static IP/port forwarding), and determine backup strategy.

Core Development

Install Docker, build a lightweight container for the Minecraft server (paper or purpur), configure autosave and resource limits, and create systemd unit or docker compose for auto-restart.

Testing

Test connectivity, performance under simulated players, and verify backups and restores.

Final Deployment

Expose service with secure port forwarding or use a VPN. Document startup, backup, and maintenance procedures.
